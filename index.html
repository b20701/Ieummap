데이터 연결 상태

서울시 공공데이터 5종을 자동으로 불러옵니다. 인증키나 API 주소를 입력할 필요가 없어요.

연결 방식

이 사이트의 서버(/api/facilities)가 서울 열린데이터광장 Open API를 대신 호출합니다. 인증키는 서버 환경변수에만 보관되며 브라우저로 전달되지 않습니다.

서울교통공사 운영 구간의 데이터만 포함되어, 다른 운영기관(코레일, 9호선, 신분당선 등) 구간 시설은 보이지 않을 수 있습니다. 실제 장애물 정보는 아직 공공 API와 연결되지 않았으며, 이용자 제보로 관리됩니다.
